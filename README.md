#  SwiftShip – Logistics & Delivery Database System

##  Overview

SwiftShip is a **relational database project** designed to simulate a logistics and shipment tracking system. It manages delivery partners, shipments, and delivery performance, enabling analysis of delays, success rates, and popular delivery locations.

This project demonstrates strong **SQL skills**, including:

* Database design
* Table relationships (Foreign Keys)
* Analytical queries
* Aggregation and ranking functions

---

## Concepts Used:

  * Joins (INNER JOIN)
  * Aggregations (`COUNT`, `GROUP BY`)
  * Window Functions (`RANK()`)
  * Date Functions (`DATEDIFF`, `CURDATE`)
  * Constraints (Primary Key, Foreign Key)

---

##  Project Flow

* Logistics performance tracking
* Delivery delay analysis
* Partner evaluation system
* Business intelligence reporting
